# 十大集合怎么选：先问「什么组织 + 什么实验」

本文件是 `SKILL.md` 第 0 节的完整展开。**每次使用本 skill 都先走这里的流程**：
问清组织与实验 → 用 `guide` 拿建议 → 用户拍板选哪几个集合 → 才在选定范围内检索。

> `guide` 子命令是这张表的可执行版本（`python scripts/gmt_lookup.py guide "..."`）。
> **改动推荐逻辑时两个地方都要同步**：`scripts/gmt_lookup.py` 里的 `GUIDE_SETS` / `SCENARIOS`
> 与本文档的表格。

## 一、为什么非要先问

MSigDB 的十个集合（H + C1…C9）是**性质完全不同的十类资源**，只有少数几条是「信号通路」：

| 用户问「帮我看看有哪些信号通路」时，如果他做的是…… | 该给 | 给错的后果 |
|---|---|---|
| 单细胞注释 | C8 细胞类型签名 | 在 H/C2 里找一个亚群标记，永远查不到 |
| 免疫浸润 / 炎症 | C7 免疫签名 | 只给 H 的 50 条，看不到免疫细胞状态 |
| CRISPR / 药物处理 | C9 扰动签名、C2 的 CGP | 拿到一堆通路名，答不了「像哪个已知扰动」 |
| 拷贝数 / 核型 | C1 位置集 | 拿到位置集当通路讲，逻辑不成立 |
| 全血/外周血转录组 | C7 + C8（含免疫细胞类型） | 把免疫细胞比例变化误读成通路激活 |

反过来，**把 10 个集合全选也同样是错的**：C5 一个集合就有 16,283 个集（GO 层级冗余严重），
全选的结果没有任何可解释性。

## 二、第 1 步：问用户的两件事

一次问完，用 AskUserQuestion（多问合并为一次调用），每题给 3~4 个常见选项 + 允许自填：

**问 1 —— 什么组织/样本（含物种）**

- 人 / 小鼠 / 大鼠 / 其他（本库是 **Hs symbols**，非人类物种需把基因转成大写人类 symbol 写法再查）
- 组织类型：肿瘤组织、正常实质组织、外周血/PBMC、免疫器官（脾/淋巴结/胸腺）、
  培养细胞系、类器官、临床患者样本

**问 2 —— 什么实验（平台 + 设计）**

- bulk RNA-seq / 芯片 的差异表达（对照组 vs 处理组）
- 单细胞 / 单核 / 空间转录组
- ChIP-seq / CUT&Tag / ATAC-seq / miRNA
- CRISPR 筛选 / siRNA 敲低 / 过表达 / 药物处理
- 只要通路基因列表，或要导出 gmt 做 GSEA

**用户已经说清就不用再问**——复述一句理解即可：
「人肝癌组织、bulk RNA-seq 的差异基因，想看该往哪些通路查，对吧？」

## 四、每个集合更适合什么场景（逐个展开）

> 这一节是 `guide` 输出的文字版（数据源在 `scripts/gmt_lookup.py` 的 `GUIDE_SETS`，两边要同步）。
> **给用户推荐时，每个集合都要带上这里 2~3 条最贴合他体系的场景**，不要只说「推荐这个」。

### H — Hallmark 标志性基因集（50 集，通路级且已收敛）

**适合的场景**

- 常规 bulk 差异基因的第一层富集：先看整体落在哪些核心过程
- 临床队列 / 多组学分组比较（高低风险、应答 vs 无应答）
- 跨数据集、跨平台比较：50 条口径统一，不同研究能对上号
- 用 GSVA / ssGSEA 给每个样本打 50 个过程的分，做连续变量分析
- 论文里需要一张「条数少、干净、好解释」的富集图

**典型产出**：GSEA / ORA 富集图；GSVA 打分成「样本 × 过程」矩阵。
**不适合**：问具体分子机制通路（粒度太粗）、看细胞类型构成。

### C1 — 位置型基因集（302 集，染色体臂 / 细胞遗传带）

**适合的场景**

- 肿瘤 CNA / CNV：把扩增或缺失区段映射成基因清单
- 染色体臂级研究（1q 扩增、9p 缺失这类经典事件）
- 白血病等血液肿瘤的细胞遗传学分组
- 位置偏倚对照：判断某个基因是否只是「跟着染色体臂一起变」的假阳性
- 全基因组区间 / 区域内基因的整体行为

**典型产出**：CNA 区段 → 基因注释；做富集时充当位置偏倚对照。
**不适合**：当功能通路讲（脚本默认已对其降权 -60）。

### C2 — 专家审编基因集（7,670 集，真信号通路的主战场）

**适合的场景**

- 用户说「找信号通路」时的主战场（KEGG / REACTOME / WP / BioCarta / PID）
- 要机制级细节：具体到受体、激酶、级联步骤——REACTOME 做得最细
- 画通路图 / 机制示意图，需要这条通路的完整基因清单（WikiPathways 有配图）
- 多数据库交叉验证：同一条通路在 KEGG 与 REACTOME 都命中，结论更稳
- 扰动类实验：CGP 子库是药物 / 过表达 / 敲低的表达签名集

**典型产出**：GSEA / ORA 富集；导出 gmt 供 clusterProfiler 或 GSEA 软件直接读入。
**不适合**：KEGG 子库只有 LEGACY 186 集，不含 PI3K-Akt / TNF 整通路。

### C3 — 调控靶标基因集（3,714 集，TFT + MIR）

**适合的场景**

- ChIP-seq / CUT&Tag / ATAC 拿到 peak 后，问「这是哪个转录因子的靶标」
- miRNA 测序或 mimics / inhibitor 实验，找下游靶基因
- 单基因通路分析：只关心某一个 TF 的下游会牵出什么
- 上游调控反推：把差异基因对应回可能的调控 TF
- 用 TFT 集合做转录因子活性打分（ssGSEA 给 TF 排序）

**典型产出**：TF / miRNA 靶基因清单；转录因子活性打分表。
**不适合**：默认对 TFT/MIR 降权；选 C3 时不要再叠 PATHWAY。

### C4 — 计算型基因集（1,006 集，共表达模块）

**适合的场景**

- 完全没有先验假设的探索：先看数据自己聚成哪些模块，再逐个注释
- 共表达网络 / WGCNA 的模块与已知模块做比对
- 肿瘤分子亚型分型（3CA 癌症共表达模块）
- 找「这套数据特有」的基因群，而不是套公共通路

**典型产出**：模块 → 基因群清单；再拿模块去做注释或分型。
**不适合**：集合名是抽象编号，本身没有生物学含义，不能当通路名解释。

### C5 — 本体基因集（16,283 集，GO + HPO）

**适合的场景**

- 标准 GO 富集，BP / CC / MF 分开报——审稿人最认的口径
- 穷尽式注释，不想漏掉细小的功能项
- GO:CC 做定位研究（膜 / 胞质 / 核 / 细胞器）
- GO:MF 做分子功能（酶活、结合、转运）
- HPO 做临床：患者表型、罕见病、变异致病性解读、表型-基因关联

**典型产出**：GO 富集三件套（BP / CC / MF）；HPO 表型富集。
**不适合**：层级冗余严重，结果动辄上千条，必须去冗余后再挑。

### C6 — 致癌签名（189 集）

**适合的场景**

- 判断样本里哪条致癌通路被激活（KRAS、MYC、E2F、β-catenin 等）
- 肿瘤分子分型与亚型间比较
- 抑癌基因失活的间接推断
- 癌旁 vs 肿瘤：看哪种致癌程序被打开
- 细胞系 panel 里把签名与药物敏感性关联

**典型产出**：致癌通路激活状态打分；肿瘤分型依据。
**不适合**：非肿瘤体系。

### C7 — 免疫签名（5,219 集，ImmuneSigDB + VAX）

**适合的场景**

- 肿瘤免疫微环境：免疫浸润程度、热肿瘤 vs 冷肿瘤
- bulk 数据推断免疫细胞组成（免疫签名打分，或做解卷积的参考）
- 感染与疫苗研究：抗病毒应答、VAX 疫苗应答签名
- 自身免疫与炎症性疾病：类风湿、IBD、银屑病等
- 免疫治疗 / 免疫检查点研究的应答分层
- 单细胞里给免疫亚群做状态注释（耗竭、记忆、活化）

**典型产出**：免疫浸润打分；免疫细胞状态标签。
**不适合**：区分度极高，非免疫样本也会命中，必须结合细胞组成解释。

### C8 — 细胞类型签名（866 集）

**适合的场景**

- scRNA-seq / snRNA-seq 的细胞类型注释（配合 marker 基因一起看）
- 空间转录组 spot / 区域的细胞构成
- bulk 解卷积（CIBERSORTx / MuSiC）的参考集
- 组织构成变化：肿瘤 vs 正常、纤维化、脂肪肝这类
- 类器官 / 共培养体系确认细胞身份

**典型产出**：细胞类型标签；bulk 样本各细胞类型占比。
**不适合**：覆盖有限，注释不到就退回「marker 基因 + H 打分」。

### C9 — 计算扰动签名（62 集，DepMap + CCLE）

**适合的场景**

- CRISPR screen / 敲低实验：敲掉之后转录组像哪个已知扰动
- 药物机制推断（MoA）：药物响应像哪个基因扰动
- 靶点验证与脱靶评估
- 细胞系 panel 里把药物敏感性与 DepMap 基因依赖关联

**典型产出**：扰动相似度匹配结果；靶点 / 药物机制的佐证。
**不适合**：只有 62 集、面窄；问机制通路别用它。

## 五、场景 → 集合组合速查

| 用户情况 | 主推 | 可叠加 | 一句话理由 |
|---|---|---|---|
| 肿瘤 bulk 转录组差异表达 | **H + C2** | C6（致癌激活）、C5（GO 注释） | H 给核心过程、C2 给具体通路，再看致癌通路是否激活 |
| 免疫 / 炎症 / 感染 / 自身免疫 / 肿瘤免疫微环境 | **C7 + H** | C2、C8（拆细胞组成） | C7 专治免疫细胞状态，H 补整体过程 |
| 单细胞 / 空间 / 细胞类型注释 / 解卷积 | **C8 + H** | C2、C7 | C8 做注释与占比，H 给 cluster 打基因集分数 |
| CRISPR / 敲低 / 过表达 / 药物处理 | **C9 + C2** | H、C6 | C9 映射已知扰动，C2 的 CGP 是海量扰动签名 |
| ChIP-seq / ATAC / 转录因子 / miRNA | **C3** | C2、H | C3 就是 TF 与 miRNA 靶标库 |
| 基础过程（代谢/缺氧/凋亡/增殖/应激），非肿瘤 | **H + C2** | C5 | H 的 50 条正好覆盖这些过程 |
| 临床 / 遗传病 / 罕见病 / 患者表型 | **C5 + H** | C2 | C5 含 HPO 5,793 个表型/疾病集，是表型分析的唯一来源 |
| 拷贝数 / 染色体 / 核型 | **C1** | C6、C2 | C1 把 CNA 区域映射到基因，功能后果再看 C6/C2 |
| 无明确假设、数据驱动找模块 | **C4 + C2** | H | C4 先看数据自聚模块，C2/H 给可读通路名 |
| 只是查一条已知通路包含哪些基因 / 导出 gmt | **H + C2**（= `PATHWAY`） | C5（GO:BP） | 经典信号通路就是 H + C2 的经典来源 |
| 完全放权（「你决定」/「都看看」） | `PATHWAY` | `PATHWAY,GOBP` 或 `H,C2,C5,C7,C8` | 覆盖最常见需求，且不会淹没在 C5 的万个集里 |

## 六、第 3 步与第 4 步：拍板与执行

推荐话术（给用户看的表：**每个集合都要带「适合什么场景」**）：

> 你这个体系（人肝癌组织、bulk RNA-seq 差异表达）我建议看这三个：
>
> | 集合 | 里面是什么 | 适合什么场景 | 用了能得到 |
> |---|---|---|---|
> | **H** Hallmark（50 集） | 50 条标志性生物学过程 | 差异基因第一层富集、队列分组比较、跨数据集可比 | 条数少、好解释的富集图 |
> | **C2** 经典通路 | KEGG / REACTOME / WP / PID 具体通路 | 要机制级细节、画通路图、多库交叉验证 | 具体通路的富集结果 |
> | **C6** 致癌签名（可选） | 癌基因激活 / 抑癌失活签名 | 判断哪条致癌通路被激活、肿瘤亚型比较 | 致癌通路激活打分 |
>
> 你想看哪一个或哪几个？定下来我就按这个范围去查通路和基因。

场景描述从 `guide` 输出的 `适合的场景` 里取，**只挑 2~3 条最贴合用户体系的**（不要整段照抄 5~6 条）。

用户拍板后，所有检索都带 `--collection`：

```bash
S="<SKILL_DIR>/scripts/gmt_lookup.py"

# 正向：在 H + C2 里找通路
python "$S" find "TNF signaling" "WNT signaling" apoptosis -c H,C2 -n 10

# 用户要某条通路的完整基因列表 + 导出
python "$S" show REACTOME_TNF_SIGNALING --format genes --csv "D:/out/tnf_genes.csv"

# 反向：确认某个基因落在选定范围的哪些通路
python "$S" gene FOXO1 -c PATHWAY

# 导出给 GSEA 用（--gmt 只有长写法，没有 -gmt）
python "$S" find "apoptosis" -c H --gmt "D:/out/apoptosis_h.gmt"
```

## 七、常见选错（反例，别犯）

- ❌ 用户做单细胞，却只在 H/C2 里找标记基因 → 标记基因在 **C8**。
- ❌ 用户做全血 bulk，只给 H → 全血的主要变异来自**免疫细胞比例**，应带 **C7 + C8**。
- ❌ 把 **C1** 的位置集当「信号通路」讲给用户。
- ❌ 把 **C4/C9** 的编号型集合名（`..._MODULE_12`）当有生物学含义的通路名解释。
- ❌ 用户没定范围就悄悄用全部 10 个集合检索，回一大堆没法解释的结果。
- ❌ 在选定范围里查不到，就默默扩大范围而不告诉用户换了集合。
