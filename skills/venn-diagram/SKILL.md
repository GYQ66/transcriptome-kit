# Venn 图：绘制 + 美化（2~5 个集合）

参考代码：`<参考脚本>/venn.R`（VennDiagram::venn.diagram，两组集合，圈外标签、
半透明填充、圈内数字）。本技能保留它的全部版式控制量，并修掉它里面 4 个不生效或
会带错的写法（见「与参考代码的逐条对照」）。

## ★ 流程：组名一律由用户手动输入，脚本不做自动识别（这一步不能省）

**脚本自己会把闸门关上**，一共两道，都跳不过去：

- **第 1 道（退出码 4 = 缺名字）**：`--set=` 缺标签、或 `--table` 模式没给
  `--by_levels` 时，脚本打印"待命名的集合清单"就退出 —— **不画图，也不拿
  文件名/列名来猜组名**。
- **第 2 道（退出码 3 = 等确认）**：名字齐了第一次跑，只打印「每一组在图上叫什么」
  并退出（退出码 3），不画图；确认之后再加 `--labels_confirmed=TRUE` 跑第二次才出图。

```
① 用户给了集合文件但还没给名字（或脚本以退出码 4 列出了待命名清单）
      ↓  把文件逐个摆给用户："这个集合在图上叫什么？"，让用户手动输入每个名字
      （不要从文件名猜、不要替用户起默认名）
② 拿到名字拼成 --set=<名称>=<文件>，先跑一次（不带 --labels_confirmed）
      <- 只打印清单，退出码 3，不出图
      ↓  把清单原样摆给用户做最后核对："这几个名字对吗？要不要改？"
③ 用户说"就这样"  -> 同一条命令加 --labels_confirmed=TRUE 再跑 -> 出图
   用户说"第 2 组改成 XXX" -> 把那个 --set= 的标签换掉，从 ② 重来（脚本会再次停下）
```

②的清单长这样（就是从日志里拿）：

```
==================== ★ 出图前请确认每组的显示名称 ★ ====================
下面每一行 = 图上那一组圈外标签长什么样（\n 表示换行）：
  1) hdWGCNA \Fibroblasts M2\n(1045)    |  1045 个 | #6e48fb | 来自 .../hd.txt
  2) HK HNS\nDependent UP\n(881)        |   881 个 | #ffa500 | 来自 .../hk.txt
  （标签在图上会渲染成 2 / 3 行；颜色与集合顺序一一对应）
```

**这个闸门不是走过场的**：每次运行都会把当前名称写进 `<outdir>/<前缀>_labels.txt`，
下一次运行会逐字比对 —— 只要名字变过（= 用户还没看过新名字），闸门就会重新关上，
必须再走一遍确认。所以"改完名直接加标志蒙过去"是不成立的。

**给用户看的措辞**：名字是用户自己逐个输进去的，②这一步主要让他核对
「图上显示名 / 基因数 / 颜色」的对应关系，尤其注意 `\n` 折行的地方
（用户往往关心"哪里断行"），并说明改名的办法（换掉对应 `--set=` 的标签）。
**在用户回复之前不要出图。**

## 一条命令就能出图（确认完之后）

```bash
S="<TOOLKIT>/skills/venn-diagram/scripts/run_venn.sh"

bash "$S" \
  --set="hdWGCNA \Fibroblasts M2=hd.txt" \
  --set="HK HNS\nDependent UP=hk.txt" \
  --outdir=./venn --prefix=foo --export_members=TRUE \
  --labels_confirmed=TRUE
```

标签里写 `\n` 就是换行（参考代码的标签是 3 行的），集合大小会自动补成 `名称\n(1045)`。

产物：`./venn/foo.pdf`、`foo.png`（默认 pdf+png，600 dpi），加 `--export_members=TRUE`
再多一份 `foo_regions.csv`（各区交集基因，分号分隔，带 BOM，Excel 直接打开）；
`foo_labels.txt` 是这次出图用的组名清单（确认留痕）。

## 输入怎么给（三选一，可混用）

| 给法 | 含义 |
|---|---|
| `--set=<标签>=<文件>`（重复 2~5 次） | 一个集合。文件 `.txt`（每行一个，逗号/分号/空白分隔也行）或 `.csv/.tsv`（默认取第 1 列，可用 `--gene_col=` 指定列名）。**标签必给 = 用户手动输入的组名**，缺了脚本退出码 4 并列出待命名文件（不会从文件名猜） |
| `--table=<表> --by=<分组列> --by_levels=UP,DOWN` | 从**一张长表**里按分组列拆集合（例：差异表的 `change` 列拆 UP/DOWN）。`--gene_col=` 指定基因列（默认第 1 列）。**`--by_levels` 必给 = 用户手动指定组名和顺序**（取值必须是表里真实存在的），不给脚本退出码 4 并列出可选值 |
| 两者混用 | 先 `--set` 再 `--table` 追加，集合顺序就是出现顺序（颜色/标签按这个顺序分配） |

**从上游直接接手**：
- GEO 芯片技能第二步的 `<前缀>_DEG.csv` → `--table=<...>_DEG.csv --by=change --gene_col=rownames --by_levels=UP,DOWN`
- 富集技能挑出来的代表基因表也可以先落成 `.txt` 再 `--set`
- 用户手上是 R 里的两个向量时，先各写一个 `.txt`（每行一个基因），别去改参考代码

## 常用参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--labels_confirmed=TRUE` | FALSE | **确认过组名了才给**。不给就只打印清单、退出码 3、不出图（见上文流程） |
| `--outdir` / `--prefix` | `.` / `venn` | 产物目录 / 文件名前缀 |
| `--format=pdf,png` | pdf,png | 可写 `pdf,png,tiff,svg` 任意组合 |
| `--width=5` / `--height=5` | 5 / 5 | 画布英寸。**2~3 组图 W≠H 会把圈拉成椭圆**，要正圆就保持相等 |
| `--dpi=600` | 600 | png/tiff 分辨率 |
| `--bg=white` | white | `transparent` 出带 Alpha 的透明背景（png/tiff） |
| `--export_members=FALSE` | FALSE | TRUE 则导出 `<前缀>_regions.csv` |
| `--fill=#6e48fb,#ffa500` | 用 `--pal` | 手填颜色（逗号分隔，要够 n 个） |
| `--pal=1` | 1 | 调色板 1=参考紫橙（前两色与参考代码完全一致）、2=npg、3=Set1、4=NEJM |
| `--cat_col=auto` | auto | 圈外标签颜色。auto = 跟 `--fill` 同色（**参考代码第二次调用里这两者顺序不一致，标签颜色和圈对不上，这里对齐了**） |
| `--alpha=0.5` | 0.5 | 填充透明度（参考代码值） |
| `--col=black` | black | 圈线颜色（**注意不是"列名"，列名是 `--gene_col`**） |
| `--lwd=1.3` / `--lty=1` | 1.3 / 1 | 线宽 / 线型（参考代码值） |
| `--cex=1.5` / `--cat_cex=1.3` | 1.5 / 1.3 | 圈内数字字号 / 圈外标签字号（参考代码值） |
| `--cat_pos=auto` | auto | 标签角度（度，0=12 点、顺时针）。auto：2 组 = `-90,90`（参考代码值，标签在正左/正右）；3~5 组 = 包默认值 |
| `--cat_dist=auto` | auto | 标签离圈的距离。auto：2~3 组 = `0.15`（参考代码值）；4~5 组 = 包默认值 |
| `--label_count=below` | below | 标签里补集合大小：`below`（名称下方 `(1045)`）/ `inline`（同一行）/ `none`。名称里已自带 `(数字)` 时不会重复补 |
| `--print_mode=raw` | raw | 圈内数字：`raw`（个数）/ `percent`（%）/ `raw,percent`（两行） |
| `--margin=0.12` | 0.12 | 每边留白占画布的比例，用视口实现（**真的生效**，见下） |
| `--autofit=TRUE` | TRUE | 出图前自动算留白，保证圈外标签不被裁 |
| `--scaled=FALSE` / `--euler_d=FALSE` | 都是 FALSE | 与参考代码一致：等大圈、强制经典 Venn。`--scaled=TRUE` 按比例缩圈；`--euler_d=TRUE` 时若有子集关系会自动改画欧拉图（仅 2~3 组有效） |
| `--sep_dist=0.05` | 0.05 | 2 组时间隙（仅 2/3 组有效） |
| `--rot=0` / `--main=` / `--sub=` | — | 整体旋转角度 / 标题 / 副标题 |

跑 `--help` 看完整说明。**图内文字一律用 ASCII**（Windows 缺中文字形，会渲染成乱码）。

## 产出

| 文件 | 内容 |
|---|---|
| `<前缀>.pdf` / `.png` / `.tiff` / `.svg` | 按 `--format` 出 |
| `<前缀>_labels.txt` | **这次出图用的组名清单**（序号/显示名/行数/集合大小/颜色/来源），
同时兼作下一跑的比对基准 —— 每次运行都会重写 |
| `<前缀>_regions.csv` | 各区交集（`region,n,genes`），仅在 `--export_members=TRUE` 时生成 |
| 控制台/`--log=` | 每个集合的大小、**组名确认清单**、**各区大小**、**各区之和 vs 唯一基因总数的交叉核对**、最终画布与留白 |

日志里的「各区大小」就是画在圈里的数字，可以逐个核对；末尾会自动对账
（各区之和 = 合计唯一基因，✓ 或 ⚠）。**先看这个对账，再看图。**
**退出码 3 = 停在"等你确认组名"、退出码 4 = 停在"等你给组名"，都不是报错**
（包装脚本会再提醒一遍）。

## 与参考代码的逐条对照（哪些改了、为什么）

| 参考代码的写法 | 真相 | 本技能 |
|---|---|---|
| `height=180, width=180, resolution=200, imagetype="pdf"` | `filename=NULL` 时**根本不建绘图设备**，这 4 个参数完全没用上（`venn.diagram` 的 `height/width/units` 默认是 `3000/3000/"px"`） | `--width/--height/--dpi/--format` 由本技能自己开设备，真的生效 |
| `margin=0.25` | VennDiagram 1.8.2 里 `margin` **已经不是** `draw.*.venn` 的参数，传进去被 `...` 吞掉，一点都不生效 | `--margin` 用 grid 视口实现，真的生效；默认 0.12 |
| `disable.logging=FALSE` + `filename=NULL` | 会在**当前目录**丢一个 `VennDiagram.<时间戳>.log` | 恒 `disable.logging=TRUE`，并把 `VennDiagramLogger` 的门槛抬到 ERROR（否则它会把整个参数列表、含全部基因名，几千行打到控制台） |
| 连续调了两次 `venn.diagram`，第二次 `fill` 换成橙/紫但 `cat.col` 没换 | 只有第二次的 `p1` 被 `grid.draw`，第一次纯属白跑；且第二次里标签颜色和圈的颜色是对不上的 | 只画一张；`cat.col` 默认跟随 `fill` |
| `cat.col=c("#6e48fb","#ffa500")` 配 `fill=c("#6e48fb","#ffa500")`（第一次调用） | 一致，是对的 | 默认就是这个 |
| `category.names` 里手写 `\n(1045)` | 数字得自己数 | `--label_count` 自动补，已自带 `(数字)` 的不重复补 |

## 关键决策点（不要替用户默默决定）

0. **★ 组名（`--set=` 的标签）必须由用户逐个手动输入，再给用户看、等他确认** ——
   这是脚本的两道硬闸门：缺名字退出码 4、没确认退出码 3，想跳过也跳不过去
   （名字一改闸门自动重关）。用户没给名字就**问**（"这个集合在图上叫什么？"），
   别拿文件名顶上、别自己编。
1. **几个集合、哪几个** —— 标签是什么（决定颜色顺序和标签文字）。用户只说
   "画个韦恩图"时，先问是哪几组、各自的基因列表在哪。
2. **要不要导出各区基因清单** —— 只出图（默认）还是同时要 `_regions.csv`。
   做"共同基因"这类事时通常是要的，但也别默认替他导出。
3. **配色** —— 默认沿用参考代码的紫/橙；换色要先问或明确告知换了哪套。
4. **画布尺寸** —— 默认 5x5 英寸（正方形 → 2/3 组的圈才是正圆）。
   用户要投稿尺寸时按他给的值来，并注意 2~3 组图 W≠H 会变椭圆。
5. **4~5 组图** —— 4 组还行，**5 组必然很挤**（数字会互相压），
   先问用户是否改用 UpSet 图（可用 `UpSetR`/`ComplexUpset`，
   或干脆只做 2~4 组）。别默默给他一张看不清的 5 组图。

## 坑（详见 `references/pitfalls.md`）

- **圈外标签被画布裁掉**：`cat.pos=±90` 时 VennDiagram 把标签锚点摆在图内
  npc≈0.016/0.984，而标签是**以锚点为中心**画的 —— 长标签必然甩出画布。
  加大留白（图形整体内缩、锚点跟着内移）才是解，单纯放大画布几乎没用。
  本技能 `--autofit=TRUE` 会量出每个文字元素的实际英寸尺寸并解出所需留白，一次算准。
- **`cat.pos=NULL` / `cat.dist=NULL` 会报错**（`Unexpected parameter length for`）。
  "不传"和"传 NULL"在 VennDiagram 里不等价 —— 本技能会把 NULL 参数整个丢掉。
- **多传的参数会被静默吞掉**：`venn.diagram` 把 `...` 转给对应的 `draw.*.venn`，
  而各 draw 函数只认自己的参数（4/5 组没有 `scaled`/`euler.d`，所有组都没有
  `margin`）。本技能会把这些被丢弃的参数列出来，不让你以为它生效了。
- **2~3 组图的圈只在正方形画布上才是正圆**（实测 5x5 长短轴比 1.000）；
  4~5 组图那种椭圆是 VennDiagram 的固有版式，跟画布比例无关。
- 其它见 `references/pitfalls.md`。

## 环境与启动

- **R**：任意 R ≥ 4.2
- **包**：VennDiagram 1.8.2、png（读回图片做裁切自检用）、futile.logger（VennDiagram 依赖）
- **首选直接用包装脚本**（它把五件事都办好了，环境变量必须在 R 启动**之前**设好）：

```bash
bash "<TOOLKIT>/skills/venn-diagram/scripts/run_venn.sh" <参数...>
```

包装脚本做的事：`TMP/TEMP/TMPDIR` 指到纯 ASCII 目录、`COMSPEC`、`unset LC_ALL LANG LC_*`
（不 unset 则含中文的路径在 R 里完全寻址不到）、POSIX 路径转 Windows 形式
（`/d/x` 交给 `Rscript.exe` 会段错误 139、无产物无报错）、自愈 PATH。
**bash 被沙箱拦时**（报 `PROGRAM BLOCKED BY SECURITY POLICY`）就手动设这五个变量后直调
`Rscript.exe`，并在同一条命令里 `export VENN_SKILL_SCRIPTS="<skills>/venn-diagram/scripts"`。

R 退出时报 `Segmentation fault(139)` 在中文用户名机器上无害 —— **判断成败看产物文件**。

## 回归基线（数字对不上说明中间出了错）

> 下列结果都是在"确认过组名"之后（即带 `--labels_confirmed=TRUE`，且组名与
> `<前缀>_labels.txt` 一致）跑出来的；不带这个标志只会得到退出码 3 和一份清单。
> 验证时记得**同一组名要连跑两次**（第一次记录、第二次出图）。

用本技能自造的测试数据（`set.seed(42)`，从 3000 个 GENE00001..GENE03000 里抽，
已人工核对过）：

| n | 集合 | 各区大小 | 对账 |
|---|---|---|---|
| 2 | 1045 / 881 | A 独有 445、B 独有 281、交集 600 | 445+281+600 = 1326 = 唯一基因总数 ✓ |
| 3 | 1045 / 881 / 700 | 348、221、408、465、97、60、135 | 和 = 1734 = 唯一 ✓ |

- 标签宽度实测（`convertWidth(stringWidth())`，cat.cex=1.3）：`hdWGCNA \Fibroblasts M2`
  = 2.52 英寸 → 这就是 5 英寸画布上需要 0.248 留白的原因
- 2 组图 `cat.pos=-90,90` 时标签锚点 = npc 0.016 / 0.984（与 `cat.dist` 几乎无关）
- 5x5 画布上椭圆的 `长轴/短轴`：n=2/3 为 1.000（正圆），n=4 为 1.75~2.33，n=5 为 1.92（固有版式）
- 命名闸门（2026-09-25 加）：`--set` 缺标签 → 退出码 4 + 待命名清单（不读文件）；
  `--table` 缺 `--by_levels` → 退出码 4 + 分组列取值清单。两者都不出图、都不猜名字。
